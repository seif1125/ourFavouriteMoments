# ✨ OurFavouriteMoments (MomentHub Engine)

Welcome to **OurFavouriteMoments**, a premium multi-tenant SaaS platform designed to act as a complete digital concierge for live events. From the initial digital invitation to post-event collaborative photo galleries, the platform generates dynamic, highly tailored mobile-first web pages accessible instantly via custom venue QR codes.

---

## 🚀 Core Features

### 1. The Invitation & RSVP Suite
* **Dynamic Web Invites:** Beautiful custom landing pages matching the event's theme (Weddings, Baby Showers, Corporate, Birthdays).
* **Real-Time RSVPs:** Seamless, one-click guest registration and guest headcount tracking for hosts.
* **Countdown & Venue Mapping:** Integrated countdown timers and interactive maps to guide guests to the venue.

### 2. The Live Event Itinerary
* **Digital Timeline:** A real-time schedule of events (e.g., Cake Cutting, Speeches, First Dance) keeping guests synchronized.
* **Live Notifications:** Important announcements displayed directly on the guest's mobile view during the event.

### 3. The Shared Memory Vault
* **Frictionless Uploads:** Zero-install, mobile-first camera uploads allowing guests to contribute photos and videos in seconds.
* **Digital Guestbook:** An interactive feed where family and friends can leave warm text messages and blessings.
* **Live Slideshow Integration:** Ability to beam the crowdsourced photo stream onto physical projector screens at the venue.

---

## 🛠️ Tech Stack

* **Frontend Framework:** Next.js (App Router, React)
* **Styling:** Tailwind CSS (Dynamic Utility-First Theming)
* **Database:** PostgreSQL (Hosted via Supabase)
* **ORM:** Prisma (Type-safe database client and migrations)
* **Deployment:** Vercel
